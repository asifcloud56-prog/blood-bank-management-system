About BBMS

The Blood Bank Management System is a web platform that digitises how blood is donated, stored and requested. It connects donors, blood labs, hospitals and administrators so that the right blood reaches the right patient faster.

Donors

Create a profile, record donations, check your 90-day eligibility and find upcoming blood camps near you.

Blood Labs

Maintain live stock with expiry dates, record donations, run camps and respond to hospital requests.

Hospitals

Send blood requests to approved labs, track their status and search the donor directory by blood group and city.

Admin

Verifies each facility's registration so only genuine hospitals and labs can join the network.

Technology

Built with HTML, CSS and JavaScript on the front end, and PHP with MySQL on the back end — runs on XAMPP.
